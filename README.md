# 石橋瞭 ポートフォリオサイト 運用ガイド

## ファイル構成
```
index.html         ページの骨組み
style.css           デザイン
script.js           表示を動かすプログラム(通常は触らなくてOK)
data/works.json     作品データ ← ここを更新する
data/site.json      About用の自己紹介・連絡先 ← ここを更新する
images/             作品画像を入れるフォルダ
```

## 作品を追加する手順(3ステップ)
1. `images` フォルダに画像ファイルを入れる(例:`brutus-1060-1.jpg`)
2. `data/works.json` を開いて、一番上に以下のような形で追記する

```json
{
  "id": "brutus-1060",
  "title": "BRUTUS No.1060",
  "category": "Work",
  "year": "2025",
  "description": "特集扉絵として制作。",
  "images": ["images/brutus-1060-1.jpg"]
}
```

- `category` は `"Work"`(仕事の絵/Homeに表示)・`"Original"`・`"Movie"` のいずれか
- `images` は配列なので、複数枚入れると詳細ページで縦に並びます
- `id` は他の作品と重複しなければ何でもOK(半角英数字とハイフン推奨)

3. 保存して、サイトを公開しているサービス(下記)に再アップロードする

## Aboutページを編集する
`data/site.json` の `bio`(自己紹介文)・`email`・`instagram`・`store` を書き換えるだけです。

## 無料で公開する方法(おすすめ:Netlify)
1. https://www.netlify.com/ にアクセスし、無料アカウントを作成
2. 「Add new site」→「Deploy manually」を選択
3. このフォルダ一式をそのままドラッグ&ドロップ
4. 数十秒で `https://ランダムな名前.netlify.app` が発行される
5. 以降、更新するときは同じフォルダをまた丸ごとドラッグ&ドロップすれば反映されます

(GitHub Pagesでも同様に無料で公開できます。GitHubにファイルをアップロードして「Pages」を有効にするだけです。)

## Wixで買った独自ドメインをそのまま使う方法
ドメインの「所有」と「サイトの置き場所」は別なので、そのまま使えます。

1. Netlifyのサイト設定→「Domain management」で独自ドメイン(例:ishibashiryo.com)を追加
2. 表示される案内(DNSレコード)をメモする
3. Wixの管理画面 →「ドメイン」→ DNS設定を開き、Netlifyから指示された内容に書き換える
4. 反映まで数時間〜24時間ほどかかります

## Google検索に表示されやすくする設定(SEO)
`index.html` の上部にすでに以下を設定してあります。作品を追加したときや紹介文を変えたときは、必要に応じて書き換えてください。

- `<title>`:検索結果に出るタイトル
- `<meta name="description">`:検索結果に出る説明文
- `og:image`:SNSでシェアされたときに表示される画像(`images/ogp.jpg` を用意して差し替えてください)

## 費用について
- ドメイン代(Wixへの支払い)以外、上記の方法であれば**基本無料**で運用できます
- 画像は今回「画像ファイルを直接置く」方式にしているため、外部の有料サービスは不要です

## もっと気軽に更新したい場合(管理画面つき)
`admin/` フォルダに、ログインして写真をドラッグ&ドロップするだけで更新できる管理画面(Decap CMS)を用意しています。
これを使うには、drag&dropでの公開ではなく「GitHub」というサービス経由でNetlifyに接続する一度きりの設定が必要です。
設定手順はチャットで案内します。設定が終われば、`https://あなたのサイト/admin` にアクセスしてログインするだけで、
Instagramのような感覚でタイトル・説明文・画像を追加/編集できるようになります。
